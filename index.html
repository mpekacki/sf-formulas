Salesforce Formula Evaluator

Paste a record, paste a formula, and see how every part of it evaluates.

Nested objects work for cross-object references (e.g. Account.Name). Use null for blank fields.

SOQL query all fields referenced by the formula

        
      

    


    

      Supported functions & operators
      
Operators: + - * / ^, & or + (concat), = == != <> < <= > >= && || !, plus infix AND OR NOT keywords. /* comments */ are supported.

      
      
Notes: dates use UTC; text comparison is case-sensitive; field types are inferred from the JSON values.
